# Supermarket Sales Analysis

## Project Overview
This project focuses on analyzing supermarket sales data to understand sales performance, customer behaviour, product categories, and branch-wise performance.

## Objectives
- Analyze overall supermarket sales.
- Identify top-performing product lines.
- Compare sales across branches.
- Understand customer purchasing behaviour.
- Analyze payment methods.
- Create an interactive Power BI dashboard.

## Tools & Technologies
- Microsoft Excel
- Microsoft Power BI
- Power Query
- GitHub

## Project Structure
- Dataset – Raw and cleaned sales data.
- Dashboard – Power BI dashboard file.
- Screenshots – Dashboard images.
- Report – Final project report.

## Dashboard Features
- Total Sales
- Total Orders
- Quantity Sold
- Average Rating
- Product Line Analysis
- Branch-wise Sales
- Payment Method Analysis
- Monthly Sales Trend

## Conclusion
This project demonstrates how data analytics and visualization can transform raw supermarket sales data into meaningful business insights.
